# 🍽 Tablia – Food Planner Android App

Tablia is an Android application that helps users plan weekly meals, discover meals, and save favorites for offline use.

## Features
- Meal of the Day
- Browse meals by category, country, and ingredient
- Meal details with video
- Favorites with offline access
- Weekly meal planning
- Firebase authentication (Email & Google)
- Guest mode
- Splash screen with animation

## Tech Stack
- Java
- MVP Architecture
- RX-Java
- Retrofit
- Room
- Firebase
- Lottie

## API
- TheMealDB API
